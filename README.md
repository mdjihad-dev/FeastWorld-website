# FeastWorld

A food-focused responsive website built with HTML and CSS. The project includes restaurant-style navigation, promotional sections, food cards, and visual content designed around a modern food brand.

## Tech Stack

- HTML5
- CSS3
- Responsive Web Design
- Font Awesome
- Bootstrap Icons

## Highlights

- Food brand hero section
- Navigation and promotional content
- Food item cards
- Responsive layout
- Icon-based UI elements

## Getting Started

Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/mdjihad-dev/FeastWorld-website.git
cd FeastWorld-website
```

## Project Focus

The project focuses on responsive frontend implementation, visual hierarchy, reusable styling patterns, and building a complete food-oriented landing page with plain HTML and CSS.
